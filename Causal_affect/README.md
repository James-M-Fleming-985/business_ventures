# 🎯 CAUSAL AFFECT - MVP WEB APPLICATION

## Overview
Causal Affect is a web-based MVP application designed to demonstrate cause-and-effect analysis and visualization.

## Current UAT Target
Using this project to test the AI Code Generator (PROJECT-004) by building real web application features.

## Architecture
- **Frontend**: React/TypeScript
- **Backend**: FastAPI/Python  
- **Database**: SQLite/PostgreSQL
- **Deployment**: Docker containers

## Development Approach
All features are built through the Control Tower AI Code Generator system:
1. Write YAML feature specifications
2. Generate code using `build_feature.py`
3. Validate web components visually
4. Iterate and refine
