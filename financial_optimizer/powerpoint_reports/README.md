# PowerPoint Reports Folder

This folder contains PowerPoint presentations generated by the Control Tower for this repository.

## 📁 Organization Structure

- **Generator Scripts**: Located in Control Tower `/reports/` (centralized)
- **Generated Presentations**: Saved here in `/powerpoint_reports/` (organized by repo)
- **Manual Work**: Download presentations from here for manual editing/appending

## 🎯 Usage

1. **Control Tower** generates presentations and saves them here
2. **User** downloads presentations from this folder 
3. **User** manually appends additional slides as needed
4. **Final presentation** ready for stakeholder distribution

## 📄 File Naming Convention

Generated presentations follow the pattern:
- `[ProjectName]_[Description]_DDMMYYYY_ControlTower.pptx`

## 🔮 Future Vision

As Control Tower expands, each repository will have its own presentation generators, all saving to their respective `powerpoint_reports/` folders.
